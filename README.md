# Luna & Leaf Storefront

A fictional botanical home-goods storefront created for an HTML/CSS web design assignment.

## Files

- `index.html` — storefront page structure
- `styles.css` — external stylesheet

## CSS Requirements

This project demonstrates all three requested CSS methods:

1. **External CSS:** `styles.css` is linked in the `<head>`.
2. **Internal CSS:** a `<style>` section in `index.html` styles `.featured-heading` and `.hero-note`.
3. **Inline CSS:** the "Shop the Collection" button contains a `style=""` attribute.

## GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html` and `styles.css`.
3. Open **Settings → Pages**.
4. Under the publishing/source option, choose the `main` branch and `/ (root)`.
5. Save and wait for GitHub Pages to publish the site.
6. Open the generated Pages URL to view the storefront.
